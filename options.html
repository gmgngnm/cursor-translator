Cursor Translator

英文を選ぶか、英単語にカーソルを合わせると、その場に日本語訳が出ます。

動作
英文を選ぶと、その場で訳が出る。選ぶ手間がもう掛かっているので待たない
選ばなくても、英単語の上でカーソルを止めるとその語の意味が出る
カーソルを止めてから訳しに行くまで。0〜5秒。短いほど早く出るが、読んでいるだけでも呼びやすくなる。ハイライト翻訳には掛からない
翻訳
鍵はそれぞれ別に覚えているので、行き来しても入れ直しは要りません
Google AI Studio で作れます。この端末の中だけに保存され、訳す相手以外には送りません
迷ったらそのまま。キーを入れると使えるモデルが候補に出ます
DeepL API の認証キー。末尾が :fx なら無料版の宛先へ送ります
Cloud Translation API を有効にしてから、認証情報 で作ったキー
