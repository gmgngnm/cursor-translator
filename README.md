# Cursor Translator（Firefox アドオン）

ページの英文をマウスでなぞって選ぶと、その場に日本語訳の吹き出しが出る。
英単語を一語だけ選んだときは、[EnGoloyd](https://gmgngnm.github.io/setsuguro/)
へ飛んでそのまま分解に入れる。

PDF は pdf.js を同梱した自前のビューアで開き、そこでも訳が出る。マーカーで線を
引き、覚え書きを付けて、書き込んだPDFを保存できる。

## 前提

Firefox 142 以降（Android 版を含めた下限）。何を外に出すのかを申告する
`data_collection_permissions`（選んだ本文を訳す相手へ送る、という申告）が
そこから入ったため、下限をそこに合わせてある。

## 入れ方（自分の Firefox で試す）

1. Firefox で `about:debugging#/runtime/this-firefox` を開く
2. 「一時的なアドオンを読み込む…」を押し、このリポジトリ直下の `manifest.json` を選ぶ
3. 読み込むと設定画面が自動で開くので、訳す相手を選んでAPIキーを入れる
   （閉じてしまっても、ツールバーのアイコン → 右上の歯車で開き直せる）

この入れ方だと Firefox を閉じるまでの命。ずっと使うなら次の「入れ直すのが面倒な
とき」を見る。

## 訳す相手とAPIキー

三択。鍵は相手ごとに別に覚えているので、行き来しても入れ直しは要らない。

| 相手 | 鍵の取り方 | 向き |
| --- | --- | --- |
| Gemini | [Google AI Studio](https://aistudio.google.com/apikey) | 翻訳専用ではない分、語の意味を汲んだ訳になる。モデルも選べる |
| DeepL | [DeepL API](https://www.deepl.com/pro-api) | 翻訳専用。無料枠のあるプランがある。末尾が `:fx` の鍵は無料版の宛先へ送る |
| Google翻訳 | [Google Cloud の認証情報](https://console.cloud.google.com/apis/credentials)（Cloud Translation API を有効にしてから） | 翻訳専用。速い |

鍵は設定画面で入れる。ツールバーの板には置いていない（板は入切と時間だけの物に
してある）。設定画面への道は三つ。

- **ツールバーのアイコン → 右上の歯車**
- `about:addons` →「拡張機能」→「Cursor Translator」→ 歯車 →「設定」
- 鍵が無いまま英文を選ぶと出る吹き出しの「設定を開く」

鍵がまだ入っていないうちは、読み込み直すたびに設定画面が勝手に開く（入っていれば
黙っている）。選んでいる相手の鍵が無いときは、板にもその旨が出る。

鍵はこの端末の `storage.local` にだけ入り、選んだ相手以外には送らない。

## PDF

**Firefox の内蔵ビューアでは動かない。** 内蔵ビューアは `resource://pdf.js/web/viewer.html`
というブラウザ内部のページとして開かれ、拡張機能はそこへ一切差し込めない。Firefox 本体の
`toolkit/components/pdfjs/content/PdfStreamConverter.sys.mjs` が、元のPDFのURLではなく
`resource://` の権限を与えているため。これはこのアドオンの問題ではなく、どの拡張機能でも
同じになる。

そこで **pdf.js を同梱して、自前のビューアを持っている**（`pdf/`）。

### 開く

- ツールバーの板の「**PDFを開く**」でファイルを選ぶ。手元のPDFはここから開けばよく、
  `file://` を開くわけではないので「ローカルファイルへのアクセス」の許可は要らない
- PDFを開いているタブで板を出すと「**このPDFをここで開く**」に変わる。押すと同じPDFを
  自前のビューアで開き直す。鍵の要るページに置かれたPDFも、ログインの記録を付けて
  取りに行く
- 行をまたいで選んだときは行の継ぎ目に空白を入れ、行末で切られた語（`reserva-` /
  `tion`）は繋いでから渡す
- ページ送りは上のプルダウンから。拡大・縮小は `−` `＋`

### 線を引く・覚え書きを付ける

- 上の「**マーカー**」を入れてから、なぞるだけ。色は隣の色見本で決める
- マーカーを入れている間は、なぞっても訳の吹き出しは出ない（線を引く方が邪魔に
  なるため）。訳したいときはマーカーを切る
- **引いた線を押すと覚え書きの欄が出る**。書いて「付ける」で付く。「線を消す」で
  その線ごと消える
- 線は紙の座標で持っているので、拡大・縮小しても同じところに残る

### 保存

- 「**保存**」を押すと、いま引いてある線を元のPDFに全部引き直して書き出す。
  覚え書きは付箋の注釈として入るので、他のPDFの道具でも読める（日本語のまま）
- **保存のたびに同じ名前で上書きする**。`Ctrl+S` でも保存できる
- ただし上書きできるのは**ダウンロードの置き場**。拡張機能はそこより外へは書けない
  ので、元のファイルがどこにあっても、書き出し先はダウンロードフォルダの同名の
  ファイルになる（`showSaveFilePicker` を持つブラウザでは、開いたファイルへ直に
  上書きする）
- **書いたまま閉じようとすると引き止める**。保存してあれば黙って閉じる
- 設定画面の「PDF → 自動保存」で、30秒・1分・5分ごとに勝手に保存させられる
  （既定は「しない」）

### 同梱している物

pdf.js の核（`pdf/vendor/`、2.8MB）と、書き込みに使う pdf-lib。CJK用の cmaps と
標準フォントは容量が大きいので入れていない。**フォントを埋め込んでいないPDFでは、
字が代わりのもので出ることがある**。字の層は中身から作られるので、そのときでも
選ぶ・合わせるは効く。足りなければ `pdf/vendor/README.md` の手順で足せる。

## 権限について

`about:addons` の「権限とデータ」に出るもの。

- **保存されたすべてのウェブサイトのユーザーデータへのアクセス**（必須）
  どのページでも選んだ文を拾うために要る。読むのは選んだところだけで、
  ページの中身を勝手に送ることはしない。「このPDFをここで開く」でPDFを取りに行くのも
  この許可を使う
- **ユーザーのコンピューター上のローカルファイルへのアクセス**（任意）
  `file:///…` で開いた手元のHTMLやテキストの中でも訳したいときに入れる。手元のPDFは
  板の「PDFを開く」から開けば済むので、この許可は要らない
- **ダウンロード**（必須）
  書き込んだPDFを保存するために要る。保存を押したときだけ使う
- **データ収集: ウェブサイトの内容**
  選んだ文を訳す相手（Gemini / DeepL / Google翻訳）へ送る、という申告

## どの版が入っているか

設定画面と板の見出しに `v1.14.0` のように出る。`about:addons` の「詳細」でも見られる。
直したはずなのに変わらないときは、まずここが古いままになっていないか見る
（`about:debugging` の「再読み込み」は、ディスク上のファイルを読み直すだけ）。

## 使い方

- **英単語にカーソルを1秒あわせる** → 選ばなくても、その語の意味が出る
- 英文をマウスで選ぶ → 下に吹き出しが出て訳が入る。右下に何で訳したかが小さく出る
- `Esc` かページの余白を押すと閉じる。× でも閉じる
- 訳文はそのままなぞって選べるので、写したいときは普通にコピーする
- 一語だけ選んだ（または合わせた）ときの訳は、裏方が起きている間だけ覚えておく。
  読んでいる間、同じ語には何度も戻ってくるため。文は覚えない（同じ物を選び直す
  ことがまず無いうえ、長い）。Firefox を閉じれば消える
- **英単語を一語だけ選んだときは「EnGoloydで開く」が出る**。押すと本体アプリが
  その単語で開き、そのまま接辞の分解に入る（`?w=単語` で渡している）
- ツールバーの板で入切できる。両方とも切っている間はアイコンが黒くなる。
  合わせて出すかどうかと、出すまでの時間（0.3〜3秒）も板で変えられる
- 入力欄（`textarea` / `input`）の中の英文も訳せる
- **PDFは同梱のビューアで開く**（下の「PDF」を見ること）

出ない場合は、そもそも出さない決まりに当たっていないか確かめる。

- 英字が2文字より少ない選択（押し間違いとみなす）
- 日本語の方が多い選択（訳す相手ではない）
- 1200字を超える選択（待ち時間と料金が跳ねるので断る）

### カーソルを合わせたとき

動かしている最中に出ては邪魔なので、**同じ字の上で手が止まってから**出る
（タッチ待機時間。既定は1秒で、設定と板で変えられる）。この待ち時間が掛かるのは
カーソルタッチ翻訳だけで、選んで訳す方（ハイライト翻訳）は待たずにすぐ訳す。
なぞっている間は出ない（手の震えぶんの遊びはある）。

- その語から離れると引っ込む。吹き出しの上へ入っている間は引っ込めない
  （中の「EnGoloydで開く」を押しに行けるように）
- 選んで出した吹き出しが出ているときは、合わせても奪わない
- 入力欄（`textarea` / `input`）の中では出ない。書きかけの文を訳しても仕方ないので
- 読んでいるだけで訳す相手を呼ぶことになるので、切りたいときはツールバーの板で切る

## 設定

| 項目 | 既定 | 何のためか |
| --- | --- | --- |
| 翻訳に使うもの | Gemini | Gemini / DeepL / Google翻訳 |
| APIキー | 空 | 相手ごとに別に持つ |
| モデル | `gemini-3.7-flash` | Gemini のときだけ使う。本体アプリと同じ既定 |
| カーソルタッチ翻訳 | 入 | 選ばなくても、英単語の上でカーソルを止めると意味が出る。ツールバーの板からも入切できる |
| タッチ待機時間 | 1秒 | 0〜5秒をバーで決める（0.1秒刻み）。カーソルタッチ翻訳だけに掛かる |
| 訳すきっかけ | 選んだらすぐ | 「訳す」を押したときだけ、にもできる（選んだときの話で、合わせたときは上の札で決まる） |
| 角の丸み・枠の太さ | 7px・1px | 吹き出しの形。バーで決める |
| 文字の大きさ | 13px | 10〜24px。添え字（相手の名前や釦）も一緒に大きくなる |
| 大きさ（横幅の上限） | 380px | 160〜800px。訳が短ければそこまで広がらずに縮む |
| 色を自分で決める | 切 | 入れると、吹き出しの背景色・枠の色・文字の色を自分で選べる。切っていれば下の「色」に従う |
| 明るさ | 自動 | 自動（端末に合わせる）／明るい／暗い |
| 色 | 青 | 青・橙・緑・灰。吹き出しと設定画面の色味が変わる |
| PDFの自動保存 | しない | 同梱ビューアで線を引いたとき、30秒／1分／5分ごとに勝手に保存する |
| ハイライト翻訳 | 入 | 英文を選ぶとその場で訳が出る。待たない |

## 入れ直すのが面倒なとき

直すたびに `about:debugging` で読み込み直すのは、手順としては最後の手段。

**1. 直しながら試すなら `web-ext`**（Node が要る）

```
npx web-ext run
```

専用の Firefox が立ち上がり、**ファイルを保存するたびに勝手に読み込み直す**。
`about:debugging` を触らなくてよくなる。

**2. 普段使いの Firefox に入れたままにするなら署名する**

AMO で「自分にだけ配る」署名（unlisted）を取れば、更新を自動で受け取れる。

```
npx web-ext sign --channel unlisted \
  --api-key "$AMO_JWT_ISSUER" --api-secret "$AMO_JWT_SECRET"
```

（鍵は https://addons.mozilla.org/developers/addon/api/key/ で作る）
出来上がった `.xpi` を GitHub Pages などに置き、`manifest.json` に
`browser_specific_settings.gecko.update_url` を足して更新情報のJSONを指せば、
以降は Firefox が自分で新しい版を拾いに行く。

**3. それまでの間**

`git pull` して `about:debugging` の「再読み込み」を押すだけでよい。
zip を落としてくる必要は無い。

## 中身

| ファイル | 役目 |
| --- | --- |
| `content.js` | ページ側。選択を拾い、影(Shadow DOM)の中に吹き出しを描く |
| `background.js` | 裏方。訳す相手を呼び、一語だけの訳を覚えておく |
| `common.js` | 設定の既定値と、相手と鍵の対応表。4か所から同じ物を読むためのもの |
| `popup.html/.js` | ツールバーの釦から出る板。入切・待機時間・相手・PDFを開く |
| `pdf/viewer.html/.js/.css` | 同梱のPDFビューア。描くのは pdf.js、書き込むのは pdf-lib（どちらも `pdf/vendor/`） |
| `options.html/.js/.css` | 設定画面（板と同じ `options.css` を使う） |

訳す相手を呼ぶのは裏方だけにしてある。ページ側から直に呼ぶと、ページごとの
CSP（外部への通信の禁止）に引っかかる上、APIキーが読んでいるページと同じ場所に
置かれることになるため。相手は `background.js` の `ENGINES` に一つ足せば増える。

単語を EnGoloyd へ渡すのも裏方の仕事。飛び先は `common.js` の
`SETTINGS_DEFAULTS.engoloydUrl` に置いてある（設定画面からは触らせていない）。
開くのは http(s) のページだけに限ってある。

吹き出しは漫画のセリフのように、元の語へ向かって左斜め上に尖らせている。先が
左上を向くので、吹き出し自体はそこから右下（上に出すときは右上）へ広がる。
指す先は語や選んだ範囲の真ん中。何行にもまたがるときは最後の行の真ん中を指す。
角の丸みと枠の太さ、色は設定から変えられる（既定は角7px・枠1px）。影や動きは
付けない。訳した元の文は出さない（読んでいるページに
そのまま在るため）。それ以外の見た目は掲示板くらいの素っ気なさで、入力欄や
釦はブラウザの見た目のまま。入切だけは、チェックの箱をそのまま横長の板に仕立てた
トグルにしている（別の要素を重ねるとキーボードや読み上げから外れるため）。
設定画面は左にラベル・右に操作の表組み、板はラベル左・操作右の一行ずつ。読んでいるページの上に出す物なので、飾るほど邪魔になる。
配色は明るい側が Yotsuba B 風、暗い側が Tomorrow 風。

吹き出しは閉じた Shadow DOM の中に作る。ページのCSSに崩されず、こちらの見た目も
ページへ漏らさないため。Gemini に渡すときはページから拾った文を目印で囲い、
本文中の指示めいた文を真に受けないようにしている（DeepL と Google翻訳は文章を
指示として読まないので、その囲みは要らない）。

### マニフェストは v2

Firefox の MV3 では `host_permissions` が入れた時点では許可されず、使う人が
後から許すまで通信できない。個人で入れて使うぶんにはその一手間が邪魔なので
v2 にしてある（Firefox は v2 を今も受け付ける）。v3 に移すときは、許可を求める
導線を設定画面に足すこと。

## 直したら

- `manifest.json` の `version` を上げる
- `web-ext lint` は `pdf/vendor/` に14件の警告を出す（`DANGEROUS_EVAL` など）。
  同梱した pdf.js のもので、こちらのコードからは0件。自分の分だけ見たいときは
  `--ignore-files "pdf/vendor/**"` を付ける
- Playwright で確かめる。作業用のファイルはリポジトリに入れず、スクラッチ領域へ置く
  （やり方は `CLAUDE.md` に書いてある。Chromium に `browser.*` の代わりを
  差し込み、訳す相手は `page.route` で差し替える）
